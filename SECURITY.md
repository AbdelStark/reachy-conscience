# Security

This guard is defense in depth, not a certified safety system. Physical emergency stop, SDK motor limits, access control, and owner supervision are independent requirements. An app must call the guard before execution and fail closed on errors. Observing a transcript after realtime audio has been queued does not guard that speech; wrapping an already-running tool path does not guard its effects. This package does not yet integrate with the Conversation App's pre-execution seams. Untrusted text must remain data, never instructions. Do not log secrets, transcripts, or images. Report vulnerabilities through GitHub's private vulnerability reporting feature.
