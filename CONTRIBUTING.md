# Contributing

The operator-paced voice host also needs `uv run conscience-voice --help` and fake-port turn/stop tests before a pull request; a clean software gate is not a robot-safety result.

Changes to an approve path require adversarial and failure-mode tests. Run `uv lock --check`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run pytest`, `uv build --out-dir dist --clear --no-build-logs`, and `python scripts/check_release_artifacts.py`. For SDK adapter changes, also run `uv sync --extra robot`, `uv run --extra robot python scripts/check_reachy_sdk_api.py`, and the fake-backend audio and motion tests. For ASR adapter changes, run `uv sync --extra asr` and `uv run --extra asr pytest tests/test_ingress.py` without fetching model weights. For local planner/TTS changes, run `uv run pytest tests/test_proposal_planner.py tests/test_local_tts.py`; the TTS smoke requires eSpeak NG and FFmpeg. For policy, ledger, owner-console, or approval-broker changes, include migration, privacy-default, malformed-input, authentication, cross-origin, exact-argument, expiry, replay, hard-stop, and no-dispatch tests. Keep I/O adapters separate from guard policy, and never include private recordings, model assets, or credentials in fixtures. Source-level checks cannot establish hardware safety, recognition quality, model behavior, or stop latency; label any untested behavior accordingly.
